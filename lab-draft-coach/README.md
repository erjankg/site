# lab-draft-coach — ИИ-кэп драфта

Изолированная песочница. Боевой код не трогает. Движок (`draft-ai/engine/*`) считает,
экраны показывают разбор и записывают то, что говорит владелец.

## Запуск

```bash
node tools/serve.mjs . 8777
```

Открыть `http://localhost:8777/lab-draft-coach/`. Сервер обязателен: страницы читают данные
по сети и пишут файлы через `POST /save`. Из `file://` работать не будет.

## Откуда кэп берёт матчапы

**Только из разметки владельца.** Скрейп `data-pipeline/matchups/*` кэп НЕ читает — переключатель
`MATCHUP_SOURCE = 'captain'` в `knowledge.js` закрывает этот источник целиком (`KB.matchups.of()`
возвращает `null`). Сами файлы остаются для страниц чемпионов сайта, их никто не трогал.

Знание растёт из двух источников, оба — не чужое мнение:

| слой | откуда | вес | где лежит |
|---|---|---|---|
| сид | механика умений (`champion-tags` + правила `matchups.json`) | 3 | секция `СИД` в `captain-matchups.txt` |
| разметка | теги на каждый ход драфта | 3→5 по подтверждениям | секция `РАЗМЕТКА` там же + `captain-annotations.json` |

```bash
node draft-ai/seed-mechanics.mjs           # отчёт: knowledge/_seed.md (482 контры, 279 связок)
node draft-ai/seed-mechanics.mjs --apply   # вписать сид в знания
node draft-ai/import-captain.mjs           # txt → champion-notes.json + synergies.namedPairs
```

Сид — это предположение по умениям, а не факт. В драфте каждая сидовая пара всплывает на вычитку:
**✓ верно** → пара становится твоей (вес растёт, текст твой), **✗ выкинуть** → пара выбывает из
расчёта навсегда (`derived.dropped`, движок её фильтрует).

## Экраны

**1 · Составы и пулы** (`teams.html`) — 2 команды × 5 игроков: имя, роль, пул чемпионов.
Пресеты под разных соперников. Пишет `draft-ai/teams.json`.
Движок режет кандидатов по пулам ДО ранжирования: пик — только пул свободного игрока,
бан — только ростер соперника. Пулов нет → старое поведение по всем 142.

**2 · Тирлист компета** (`tiers.html`) — доска S+…D, все 142 разложены по эффективному тиру
(твой, иначе соло-сид), соло-WR рядом. Драг или клавиши `1-6`, `0` — сброс к соло.
Пишет `draft-ai/knowledge/captain-tiers.json` → `notes.tiers`.

**3 · ИИ-кэп + разметка** (`coach.html`) — драфт по `WR_DRAFT_SEQUENCE`, обе стороны ведёт владелец.

- Панель вариантов с ПОЛНЫМ разбором: весь `why[]`, строка `cost`, «доживёт до хода N».
- 👍/👎 на каждом рассуждении → `draft-ai/feedback.json` (датасет для ручной подкрутки весов).
- **Разметка хода**: после каждого пика/бана — «Почему этот ход?» с мультивыбором тегов.

| клавиша | что делает |
|---|---|
| `1`-`9` | поставить тег |
| `Enter` | записать разметку |
| `Esc` | пропустить ход без разметки |
| `/` | поиск чемпиона · `⌫` отменить ход · `1`-`3` поставить ход варианта N |

## Словарь тегов → куда ложится знание

| группа | теги | поле знаний |
|---|---|---|
| мета | супер-мета · компет-темп · упал из меты · ситуативный | `notes.tiers` (вверх/вниз) |
| роль | в нашем пуле · во вражеском пуле · мейн соперника · флекс | `notes.flex`, `notes.flags` |
| драфт | безопасный FP · форс-пик · ломает наш план · под нашу стратегию | `notes.flags` |
| линия | выигрывает · переживает · нужен приоритет леса | `notes.flags` |
| контра | контрит → · контрит наш пик → | пара в `captain-matchups.txt` |
| синергия | синергия с → | `synergies.namedPairs` |
| функция | закрывает (фронт/вейв/энгейдж/пил/дамаг) | `notes.flags` |
| бан | мета у врага · снимаем комфорт · снимаем флекс | `notes.flags` |

Сырьё целиком (ход, сторона, чемпион, теги, цели, дата) — в `captain-annotations.json`.
Уверенность = сколько раз подтверждено: вес пары 3 → 4 → 5.
