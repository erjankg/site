# wr-formulas.md — формулы механик Wild Rift для калькулятора урона

Источник: ресёрч Gemini (2026-07-25), сверен Эржаном. WR ≠ LoL PC (макс.уровень 15, крит 175%,
плоское пробитие без леталити-от-уровня). Уверенность помечена; 90%-пункты сверить перед релизом.

## 1. Ускорение умений (Ability Haste) → КД — 100%
`CDR = 1 − 100/(100+AH)` · `Итоговый КД = Базовый КД × 100/(100+AH)`
Стак аддитивный. Потолка НЕТ. Частота линейна, сам % CDR — убывающая отдача. Как в LoL PC S11+.

## 2. Пробитие брони — 95%
Порядок: (1) плоское снижение → (2) % снижение → (3) % пробитие → (4) плоское пробитие.
`Armor_eff = ((Armor_base + Armor_bonus − Red_flat) × (1−Red_%)) × (1−Pen_%) − Pen_flat`
Множитель: `Armor_eff ≥ 0 → 100/(100+Armor_eff)` · `Armor_eff < 0 → 2 − 100/(100−Armor_eff)`
Пробитие НЕ опускает броню ниже 0; снижение (reduction) — может (урон >100%).
WR: плоское пробитие сразу в полном объёме, без динамической леталити от уровня.

## 3. Пробитие маг.сопр. — 95% (аналогично броне)
`MR_eff = ((MR_total − Red_flat) × (1−Red_%)) × (1−Pen_%) − Pen_flat`, множитель тот же.

## 4. Стойкость (Tenacity) — 95%
Мультипликативно: `Tenacity = 1 − Π(1−Tᵢ)`. Пример 30%+20% = 44%.
Сокращает: стан/замедление/root/silence/taunt/fear/charm. НЕ сокращает: подброс/подавление/стазис.
Минимум длительности CC = 0.3с.

## 5. Вампиризм — 95%
Физ-вамп → только физ.урон · маг-вамп → только маг.урон · омнивамп → любой (вкл. чистый).
Штраф AoE: лечение режется до 33.3% (1/3). Однотипные стакаются аддитивно.

## 6. Сила лечения и щитов — 90%
`Итог = Базовое × (1 + HealShieldPower%)`. На вампиризм НЕ влияет (для вампа — Spirit Visage-эффект).

## 7. Реген HP/маны (в единицах за 5с) — 90%
+% base regen: `Итог/5с = BaseRegen × (1+%BonusBase) + FlatBonus` (умножает ТОЛЬКО базовый реген).
% Max HP regen (Second Wind/Warmog): `MaxHP × %`. % base стакаются аддитивно.

## 8. Крит — 95%
Базовый множитель WR = 175% (×1.75). Бесконечный Клинок +30% → 205% (×2.05).
Крит-шанс >100% сгорает (искл. Ясуо/Ёнэ/Триндамир: 1% overcap = 0.8 AD).

## 9. Скорость атаки — 95%
`Total AS = Base AS × (1 + BonusAS%)`. Потолок 2.50/с (снимается Lethal Tempo и т.п.).
Он-хит срабатывает 1 раз на автоатаку → он-хитов/сек = Total AS.

## 10. Он-хит (BotRK, Trinity) — 95%
Разные предметы стакаются (урон одновременно). Именные пассивки (Spellblade) НЕ стакаются —
срабатывает один, с приоритетом наибольшего урона. На умениях — только если явно «applies on-hit»
(Q Эзреаля/Фиоры, автоатака Люциана). Обычные умения он-хит не активируют.

## 11. Ускорение предметов (Item Haste) — 90%
`КД предмета = Базовый × 100/(100+ItemHaste)`. На активки/пассивки предметов.

## 12. Рост базы цели по уровням (1–15) — 90% (кривая Riot)
`Stat(n) = Base + Growth × (n−1) × (0.7025 + 0.0175×(n−1))`
n=1 → Base · n=15 → Base + 13.265×Growth.

## 13. Скейл умений/пассивок от уровня — 90%
Умения: 4 ранга (ульта 3), скейл от РАНГА. Пассивки/предметы: от уровня чемпа (ступени 1/5/9/13 или линейно).

## 14. Частые ошибки калькуляторов
%HP-урон проходит через резисты (кроме чистого) — не вычитать из HP напрямую.
Чистый урон игнорит резисты и снижения, но не усиливается % пробитием.
Усиления урона из разных источников УМНОЖАЮТСЯ, не складываются.
Вампиризм на AoE — делить на 3. Не тащить динамическую леталити из ПК.

## 15. UI лучших калькуляторов
Разбивка по цвету типов: физ=оранж · маг=синий · чистый=белый · он-хит=фиолет/зелёный.
Раздельные ползунки уровня цели / HP / брони / MR. Галочки условных баффов (Spellblade/крит).

## ⚙️ ПОРЯДОК ВЫЧИСЛЕНИЯ ФИНАЛЬНОГО УРОНА (движок)
1. Raw = база умения/атаки + скейлы (AD/AP).
2. Крит: если крит → Raw × (1.75 + IE + пассивки).
3. Он-хит: + BotRK(%HP) + Wit's End(flat) + Trinity(Spellblade)…
4. Усиления атакующего: (Raw + OnHit) × (1 + %ампы рун/предметов).
5. Эффективная броня/MR цели (формулы §2/§3).
6. Множитель резиста (§2).
7. Урон после защиты = п.4 × множитель.
8. + чистый урон. = ФИНАЛ.
