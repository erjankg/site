# jungle-economy.json — экономика карты Wild Rift

Данные для **интерактивной Карты** (MASTERPLAN Э2/Э5): ползунок «минута игры» сверху → золото/дез-таймер/спаун объектов. Это **только данные**, UI не трогается.

## Как устроен файл

Один JSON, 5 смысловых секций + источники:

| Секция | Что внутри |
|--------|-----------|
| `_meta` | патч, легенда флагов, список нерешённого (`unresolved`) |
| `jungleCamps` | Синий/Красный бафф, Громп, Волки, Raptors, Скатл — золото/опыт/спаун/респаун/бафф |
| `minions` | типы (melee/caster/siege/super), золото за каждого, состав волны, каденция осадного |
| `epicMonsters` | стихийные драконы (4 типа + баффы), Старший дракон, Герольд, Барон — золото/спаун/респаун/бафф |
| `scaling` | ядро ползунка: рост золота со временем + дез-таймер по уровню/минуте |
| `sources` | ссылки-источники + что из них взято |

## ⚠️ Точно / ДЕМО — читать перед показом

**НЕ выдумывал молча.** У каждого числа флаг:
- `"sourced": true` — подтверждено источником из `sources[]` (баффы, золото кэмпов, таймеры объектов, баффы драконов/Барона/Герольда, скейл баффов 140→215→220).
- `"demo": true` — **плейсхолдер**, точного числа для актуального патча найти не удалось. В UI показывать как «≈/демо», свериться вручную. Причина частая: Fandom-страница `Gold (Wild Rift)` (целевой источник per-type золота миньонов) отдаёт боту `402 Payment Required`.

**Что осталось ДЕМО (см. `_meta.unresolved`):**
1. Точное per-type золото/опыт миньонов (7.x).
2. Золото Raptors, XP кэмпов/объектов.
3. Формула дез-таймера чемпиона (Riot не публикует; max lvl WR = 15 ≠ 18 ПК). Таблица `scaling.deathTimer.approxTableDemo` — приближение.
4. Число баффа Cloud Dragon.

**Расхождения по патчам** (спаун дракона/Барона/Герольда менялся) даны в полях `*_byPatch` (`older` = 2020-2021, `p6` = патч 6.0): напр. Барон 10:00→12:00, Герольд 6:00→5:00, дракон 4:00→5:00.

## Обновление

Скрипта-фетчера нет намеренно: **у Wild Rift нет открытого API экономики** (см. память `data_source`). Данные собраны ручным ресёрчем по офиц. патчнотам + WR-вики. Обновлять при смене патча вручную, сверяя `demo`-поля в игре и заполняя `unresolved`.
