# ФОРМАТ:   кто > кого   линия   [вес]   — почему
#           Олаф > Вуконг  топ  4  — Олаф передерживает его в размене, ульта снимает контроль
#
#   кто > кого   — левый БЬЁТ правого. Имена как удобно: Олаф, Olaf, олаф.
#   линия        — топ / лес / мид / дракон / саппорт. Можно пропустить — тогда на всех линиях.
#   вес          — 3 обычная контра, 4 уверенно, 5 разбирает всухую. Можно пропустить, будет 4.
#   — почему     — что коуч скажет вслух. Можно пропустить, но лучше писать: это и есть ценность.
#
# ЧТО ЭТО ДАЁТ:
#   • Твоя строка ПЕРЕБИВАЕТ скрейп. Если там записано наоборот — твоё побеждает,
#     а неверная пара выкидывается из расчёта.
#   • Работает на фирлес: коуч сам поймёт, что контра сгорела и чемпа можно брать вслепую.
#
# Строки с # — комментарии, движок их не читает. Пиши сколько хочешь, порядок неважен.
