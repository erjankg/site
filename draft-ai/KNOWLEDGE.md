# КАПИТАНСТВО — мозг драфта

Закрытая система для капитанов и тренеров. Знает **только драфт Wild Rift**: матчапы, комбо,
контры, тир, фирлес-теорию. Ничего из остального сайта сюда не подмешивается.

## Железное правило области знаний

Движок читает **только**:

| Откуда | Что берёт |
|---|---|
| `draft-ai/knowledge/*` | правила драфта, паттерны, архетипы, синергии (этот мозг) |
| `data-pipeline/matchups/*.json` + `matchups.json` | кто кого бьёт + «почему» + политика доверия к цифрам |
| `data-pipeline/champion-tags.json` | механики чемпиона и какие функции состава он закрывает |
| `data-pipeline/wr-stats.json` | тир/винрейт/пикрейт/бан-рейт по рангам |
| `data-pipeline/jungle-economy.json` | тайминги объектов — для логики «ранняя игра против поздней» |

Больше **ничего**. Ни `app.js`, ни общей памяти сайта, ни чужих проектов.

## Про цифры — читать обязательно

`matchups.json.policy` решает, доверять ли процентам, и считается **автоматически** по возрасту
данных. Сейчас: `useStatWinrate: false` — источник не обновлял винрейты матчапов 126 дней.

Значит движок:
- **не показывает** проценты матчапов и **не берёт их в вес**;
- **берёт направление** пары («Джакс забирает Камиллу») — оно из механики, не протухает;
- **берёт редакционные контры** и **теги механик** для объяснения;
- **берёт свежий тир и винрейт чемпионов** из `wr-stats.json` — эти данные ежедневные и живые.

Источник оживёт → политика включит проценты сама, править код не нужно.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `knowledge/patterns.json` | фирлес-паттерны: отказ, дабл-пик, форс, контр-пик, флекс, безопасный первый пик |
| `knowledge/draft-rules.json` | правила драфта с весами: что хорошо, что штрафуется, и почему |
| `knowledge/archetypes.json` | архетипы составов и кольцо «кто кого бьёт» |
| `knowledge/synergies.json` | связки: правила по механикам + именованные пары |
| `knowledge/timing.json` | окна силы (ранняя/средняя/поздняя) и правила про темп карты |
| `knowledge/champion-notes.json` | ручные заметки владельца — перебивают всё остальное |

## Как добавить своё правило (для владельца)

Открыть `knowledge/champion-notes.json` и дописать блок:

```json
{
  "if": "враг взял Фиору на топ",
  "then": "не бери Олафа вслепую",
  "because": "Фиора разбирает Олафа в дуэли, а он мастхев — потеряешь и линию, и чемпа",
  "weight": 3
}
```

`weight` — насколько это важно: 1 подсказка, 3 серьёзно, 5 железно.
Ручные заметки всегда сильнее автоматических правил.

## Чего движок не делает

- Не выдумывает матчапы. Проверено: ИИ угадывает контры на 8% — хуже случайного.
  Пары берутся из данных, ИИ только **объясняет** уже известную пару.
- Не выдаёт себя за нейросеть. Это честная считалка, которая всегда показывает разбор.
- Не показывает числа без даты и источника.
